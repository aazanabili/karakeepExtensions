# TabSync Dashboard

إضافة Manifest V3 واحدة تعمل على **Chrome** و **Edge** دون أي تعديل: تزامن مجموعات التبويبات مع قوائم **Karakeep** أو **ملفات TXT محلية** (مرآة كاملة، أحادية الاتجاه)، مع لوحة تحكم في صفحة التبويب الجديد.

A single Manifest V3 extension for **Chrome & Edge**: mirrors tab groups to **Karakeep** lists or **local TXT files** (one-way full mirror), with a fast searchable New Tab dashboard.

## التثبيت | Install

1. Chrome: `chrome://extensions` — Edge: `edge://extensions`
2. فعّل **وضع المطوّر / Developer mode**
3. **Load unpacked** واختر هذا المجلد
4. ستُفتح صفحة الإعدادات تلقائياً عند أول تثبيت

## الإعداد | Setup

> **نظام التخزين حصري**: إما Karakeep **أو** مجلد TXT — نظام واحد فقط يعمل في كل مرة (اختيار من الإعدادات).

### خيار 1: Karakeep
1. أنشئ مفتاح API من `Karakeep → Settings → API Keys`
2. في إعدادات الإضافة: أدخل رابط السيرفر (مثل `https://try.karakeep.app`) والمفتاح
3. **Test connection** — تمنح الإضافة صلاحية الوصول لذلك النطاق فقط
4. Save — تبدأ المزامنة تلقائياً

### خيار 2: مجلد TXT محلي
1. اختر **Local TXT folder** ثم **Choose folder**
2. كل مجموعة تبويبات = ملف `GroupName.txt` (رابط في كل سطر)

#### الصلاحية الدائمة (حل نهائي — مرة واحدة فقط)
بسبب قيود أمان Chromium، صلاحية المجلد للإضافات تكون **للجلسة الواحدة افتراضياً**. لجعلها **دائمة للأبد** (لا تُطلب بعد إغلاق المتصفح):

1. في صفحة إعدادات الإضافة، قسم «مجلد TXT محلي»، اضغط زر **«فتح إعدادات الإضافة / Open extension settings»**
2. في الصفحة التي تفتح، ابحث عن قسم **«الوصول إلى الملفات / File access»** أو **«إعدادات الموقع → تحرير الملفات / File editing»**
3. غيّر الإعداد من «السؤال / Ask» إلى **«السماح / Allow»**

هذا إعداد متصفح دائم لا يتغير بإعادة التشغيل. (المصدر: قيود موثقة في Chromium — crbug.com/376939529 — نافذة «السماح في كل زيارة» الثلاثية غير متاحة لصفحات الإضافات `chrome-extension://`).

## كيف تعمل | How it works

| الحدث | السلوك |
|---|---|
| فتح/إغلاق/نقل/تعديل تبويب أو مجموعة | مزامنة كاملة بعد **2.5 ثانية** من آخر حدث (debounce) |
| إغلاق تبويب | إزالة الرابط من قائمته + **أرشفة** (افتراضي) أو حذف نهائي — حسب الإعداد |
| إغلاق مجموعة كاملة | تبقى القائمة على السيرفر كـ**أرشيف** (شارة «محفوظ») ولا تُفرَّغ — قابلة للاستعادة من اللوحة |
| تبويبات خارج المجموعات | تذهب لقائمة `non` (الاسم قابل للتغيير) |
| مجموعة بلا عنوان | تُعامل كـ `non` |
| نفس اسم المجموعة في نافذتين | **دمج** في قائمة واحدة |
| فشل الاتصال | العمليات تبقى معلّقة وتُعاد بعد دقيقة (ثم كل 5 دقائق) — شارة `!` حمراء على الأيقونة |

- **اللوحة تعرض كل شيء**: المجموعات المفتوحة الآن (شارة «مفتوح الآن») + كل قوائم السيرفر الأخرى (شارة «محفوظ»).
- **المزامنة تدير المفتوح فقط**: القوائم المؤرشفة لا تُعدَّل ولا تُحذف تلقائياً أبداً.
- **الأمان**: لا تُحذف أو تُفَرَّغ إلا القوائم المفتوحة حالياً في المتصفح (قوائمك الأرشيفية وقوائمك الأخرى في Karakeep لا تُمسّ).
- **الروابط السريعة**: قسم ثابت أعلى اللوحة، يُخزَّن محلياً + يُزامَن مع Karakeep كقائمة `QuickLinks` (وضع حماية ذاتية — إضافة فقط، لا حذف تلقائي من السيرفر).
- **شريط محركات البحث**: بارز وأساسي (Google/Bing/DDG/YouTube/Wikipedia/sear.zanabili.work)، يفتح في تبويب جديد، والمحرك المختار يُحفظ كافتراضي.
- **تطهير الروابط**: إزالة `utm_*` و`fbclid` وغيرها + توحيد YouTube (`?v=`).
- **الاستعادة**: من اللوحة — فتح القائمة كنافذة جديدة مع إعادة إنشاء المجموعة بنفس الاسم واللون، وتجميد المزامنة 30 ثانية لمنع حلقات التكرار، وخمول التبويبات الخاملة فوراً (توفير RAM).

## البنية | Structure

```
manifest.json
src/
  background/   sw.js (events, debounce, retry, badge) · sync.js (mirror engine)
  lib/          normalize.js · settings.js · i18n.js · drivers/karakeep.js · drivers/localfs.js
  newtab/       لوحة التحكم (بحث فوري، بطاقات، استعادة)
  popup/        حالة المزامنة + سجل العمليات + مزامنة يدوية
  options/      الإعدادات + تصدير/استيراد JSON
icons/
```

## ملاحظات معروفة | Known limitations

- ألوان المجموعات تُخزَّن محلياً فقط (Karakeep لا يدعم الألوان) — تُستعاد على نفس الجهاز.
- `tabs.discard` لا يعمل على التبويب النشط (يُستثنى تلقائياً).
- الصلاحيات الممنوحة للنطاقات اختيارية وتُطلب عند الحاجة فقط (أثناء اختبار الاتصال).
