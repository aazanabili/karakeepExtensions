# TabSync Dashboard

إضافة Manifest V3 واحدة تعمل على **Chrome** و **Edge** دون أي تعديل: تزامن مجموعات التبويبات ثنائي الاتجاه مع حالة مركزية في **Karakeep** أو **ملفات TXT محلية**، مع لوحة تحكم في صفحة التبويب الجديد.

A single Manifest V3 extension for **Chrome & Edge**: synchronizes tab groups bidirectionally with central state in **Karakeep** lists or **local TXT files**, with a searchable New Tab dashboard.

## التثبيت | Install

1. Chrome: `chrome://extensions` — Edge: `edge://extensions`
2. فعّل **وضع المطوّر / Developer mode**
3. **Load unpacked** واختر هذا المجلد
4. ستُفتح صفحة الإعدادات تلقائياً عند أول تثبيت

## الإعداد | Setup

> **نظام التخزين حصري**: إما Karakeep **أو** مجلد TXT — نظام واحد فقط يعمل في كل مرة (اختيار من الإعدادات).

### خيار 1: Karakeep
1. أنشئ مفتاح API من `Karakeep → Settings → API Keys`
2. في إعدادات الإضافة: أدخل رابط السيرفر (مثل `https://try.karakeep.app`) والمفتاح
3. **Test connection** — تمنح الإضافة صلاحية الوصول لذلك النطاق فقط
4. Save — تبدأ المزامنة تلقائياً

### خيار 2: مجلد TXT محلي
1. اختر **Local TXT folder** ثم **Choose folder**
2. كل مجموعة تبويبات = ملف `GroupName.txt` (رابط في كل سطر)

#### صلاحية المجلد
يُحفظ مرجع المجلد في IndexedDB، لكن Chromium قد يطلب تأكيد صلاحية الكتابة مجدداً بعد إعادة تشغيل المتصفح. عند ظهور تنبيه الصلاحية في الإعدادات، انقر على اسم المجلد لمنحها من جديد؛ لا يستطيع Service Worker طلبها دون تفاعل مباشر من المستخدم.

## كيف تعمل | How it works

| الحدث | السلوك |
|---|---|
| تشغيل المتصفح | مطابقة كاملة مع الحالة المركزية: فتح الناقص، إغلاق الزائد، واستعادة المجموعات والترتيب |
| فتح/إغلاق/نقل/تعديل تبويب أو مجموعة | فحص أحدث حالة في التخزين ثم إعادة تطبيق تعديل المستخدم عليها بعد **2.5 ثانية** من آخر حدث |
| إغلاق تبويب أو تغيير رابطه | إزالة الرابط من قائمته وإرساله إلى أرشيف Karakeep أو `Archive.txt` |
| نقل تبويب بين المجموعات | تحديث المجموعتين دون أرشفة الرابط |
| إغلاق مجموعة كاملة | تبقى القائمة ومحتواها محفوظين ولا تُحذف أبداً؛ تُعاد عند المطابقة التالية |
| تبويبات خارج المجموعات | تذهب إلى `non`، مع استثناء التبويبات المثبتة من المزامنة |
| مجموعة بلا عنوان | تُعامل كـ `non` |
| نفس اسم المجموعة في نافذتين | **دمج** في قائمة واحدة |
| فشل الاتصال | العمليات تبقى معلّقة وتُعاد بعد دقيقة (ثم كل 5 دقائق) — شارة `!` حمراء على الأيقونة |

- **مزامنة صامتة دورية**: تفحص الإضافة التخزين كل دقيقة لاستقبال تغييرات الأجهزة الأخرى دون إشعار أو إعادة تحميل التبويبات الموجودة.
- **التخزين هو الحالة المركزية**: عند اختلاف المتصفح عن التخزين، تُعتمد أحدث نسخة من التخزين ثم يُعاد تطبيق تعديل المستخدم إن كان قابلاً للتطبيق.
- **كل قوائم التخزين**: كل قائمة Karakeep وكل ملف TXT صالح يدخل في الجلسة المركزية، باستثناء QuickLinks وArchive وملفات TabSync الداخلية.
- **Metadata Karakeep**: تضيف TabSync علامتها وترتيب المجموعة إلى وصف القائمة مع الحفاظ على الوصف الأصلي الموجود قبله.
- **المجموعات لا تُحذف**: إنشاء وتحديث فقط. إغلاق المجموعة يحفظها بمحتواها، بينما حذف التبويب وحده يزيل الرابط ويؤرشفه.
- **ترتيب التبويبات**: محفوظ لكل قائمة في metadata الخاصة بـ TabSync داخل Karakeep، ومحفوظ في ملفات TXT حسب ترتيب الأسطر.
- **الروابط السريعة**: قسم ثابت أعلى اللوحة، ومصدرها نظام التخزين المختار حصرياً. قبل أي إضافة أو تعديل أو حذف أو إعادة ترتيب، تقارن الإضافة الكاش المحلي بآخر نسخة من Karakeep أو `QuickLinks.txt`. عند التطابق تنفذ العملية وتكتبها في التخزين. عند الاختلاف تلغي العملية وتحمّل نسخة التخزين لأن التخزين يفوز دائماً عند التعارض.
- **ترتيب الروابط السريعة**: في Karakeep يُحفظ كبادئة مرقمة مثل `01 - Google`. في الوضع المحلي يُحفظ `QuickLinks.txt` بصيغة `01 - العنوان` ثم فاصل Tab ثم الرابط.
- **شريط محركات البحث**: بارز وأساسي (Google/Bing/DDG/YouTube/Wikipedia/sear.zanabili.work)، يفتح في تبويب جديد، والمحرك المختار يُحفظ كافتراضي.
- **تطهير الروابط**: إزالة `utm_*` و`fbclid` وغيرها + توحيد YouTube (`?v=`).
- **الاستعادة**: من اللوحة — فتح القائمة كنافذة جديدة مع إعادة إنشاء المجموعة بنفس الاسم واللون، وتجميد المزامنة 30 ثانية لمنع حلقات التكرار، وخمول التبويبات الخاملة فوراً (توفير RAM).

## البنية | Structure

```
manifest.json
src/
  background/   sw.js (events, debounce, retry, badge) · session.js (central session engine) · sync.js (quick links/cache)
  lib/          session-state.js · quick-links.js · normalize.js · settings.js · i18n.js · drivers/
  newtab/       لوحة التحكم (بحث فوري، بطاقات، استعادة)
  popup/        حالة المزامنة + سجل العمليات + مزامنة يدوية
  options/      الإعدادات + تصدير/استيراد JSON
icons/
```

## ملاحظات معروفة | Known limitations

- ألوان المجموعات تُحفظ في وصف قائمة Karakeep أو في `_TabSyncSession.txt` للوضع المحلي.
- قوائم Karakeep الذكية والقوائم ذات صلاحية القراءة فقط تظهر في المتصفح، لكن تعديلها من المتصفح يُلغى لأن Karakeep لا يسمح بتغيير عضويتها عبر API.
- `tabs.discard` لا يعمل على التبويب النشط (يُستثنى تلقائياً).
- الصلاحيات الممنوحة للنطاقات اختيارية وتُطلب عند الحاجة فقط (أثناء اختبار الاتصال).
